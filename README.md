# 治愈萌宠

步数养宠 + 种花园 微信小游戏

> 当前状态：**核心循环 Demo 阶段**。数据模型和可玩 Demo 已完成，未接微信云开发、未接微信运动 API、未上线。

## 快速开始

直接用浏览器打开 `index.html`，即可体验核心循环（零依赖，不需要安装任何东西）。

- 拖动「模拟步数」滑块 → 看步数如何驱动小柴犬成长、进化
- 点「喂食」「抚摸」→ 看成长值和心情变化
- 三个进化阶段：幼犬 → 成长期 → 成年（戴红围巾）

## 核心设计

**一句话循环**：走路 → 步数转化为成长值 → 柴犬进化 → 想再看一眼

数据模型要点（见 `PetModel.ts`）：
- 3 阶段进化：幼犬（0）→ 成长期（300）→ 成年（1000）
- 步数按 1 步 = 0.05 成长值转化，走路本身就能让宠物成长
- 心情 0-100，随时间衰减（每小时 -2），制造"回来看看"的理由
- 离线衰减逻辑：精力随时间恢复，心情随时间下降

## 当前最重要的未验证假设
